StanoChillArt

Eine kleine Familie von Werkzeugen fürs Telefon.

Ich schreibe Android-Apps für mich. Ein Programm, das seine Arbeit macht und sonst nichts. Jedes bleibt klein. Es macht eine Sache. Kein Konto, keine Werbung, kein Tracking. Offline, wenn es geht. Das gilt für alle, die hier sind.

Keine Anmeldung, keine Banner, keine Nutzungsdaten, die weggeschickt werden. Ein Teil geht auch ohne Netz. Wenn dir eine gefällt, lade sie herunter. Ein Stern auf GitHub ist Dank, dass es sich lohnt, sie zu machen und zu teilen.
