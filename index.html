StanoChillArt

A small family of instruments for the phone.

I write Android apps for myself. A program that does its job and nothing else. Each one stays small. It does one thing. No account, no ads, no tracking. Offline when it can. That holds for every app here.

No sign-up, no banners, no usage data sent away. Some of it works without a network. If you like one, download it. A star on GitHub is thanks, that making them and sharing them is worth it.
